## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 15, React, Tailwind CSS, shadcn/ui |
| Backend | Supabase (PostgreSQL, Auth, Storage) |
| Forms | React Hook Form, Zod |
| Tables | TanStack Table |
| Charts | Recharts |
| Deployment | Vercel |
| Version Control | GitHub |
